# Writing preferences

- Use simple, clear English in code comments, documentation, and responses.
- Keep wording professional and suitable for panelists and other readers.
- Explain what the code does and why the step is needed. Avoid unnecessary jargon.
- Do not prefix code comments with labels such as "Defense:".
- Keep useful explanations in comments; do not remove them just to remove a label.

# Dependency installation

- The user installs dependencies personally. Do not install or upgrade dependencies, or request approval to run dependency installation commands.
- When dependencies are needed, explain which packages and versions are required and provide commands for the user to run. Continue independent work and clearly identify checks blocked by missing dependencies.
